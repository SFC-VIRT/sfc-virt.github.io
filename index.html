VIRT (SFC-RG)

VIRT について

Virt は、現代のクラウドコンピューティングの基盤である仮想マシンインフラストラクチャの発展に取り組む研究チームです。 ハイパーバイザからハードウェアアクセラレータまで、仮想化のフルスタックにわたる課題に挑戦しています。

  • Fast Virtual Machine Live Migration in Environments with Significantly Low CPU Cache Hit Rates
  • Application operating core aware 100GbE NIC on FPGA
  • Secure Virtual Partitioning and Provisioning of SmartNICs in Multi-tenant IaaS
